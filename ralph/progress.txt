## Codebase Patterns
- Existing typecheck errors in `.next/` directory (generated Next.js files) and `history/` and `scripts/` directories - these are pre-existing and unrelated to refactoring work
- The `src/lib/pipeline/` directory contains the ranking pipeline components
- Recency scoring uses exponential decay formula: `0.2 + 0.8 * 2^(-ageDays / halfLifeDays)`
- Database abstraction: Use `getDbClient()` from `src/lib/db/driver.ts` for cross-database compatibility (SQLite dev, PostgreSQL prod)
- When querying with driver abstraction, cast result rows through `unknown` for type safety: `result.rows[0] as unknown as MyType`
- For upserts, check `db.driver` property and use PostgreSQL's `ON CONFLICT ... DO UPDATE SET col = EXCLUDED.col` vs SQLite's `INSERT OR REPLACE`
